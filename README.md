# Lanlok — сайт с командами бота

Статический сайт, работает на GitHub Pages без сборки.

## Запуск на GitHub Pages
1. Создай репозиторий и загрузи в корень все файлы из этой папки.
2. Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет по адресу `https://<ник>.github.io/<репозиторий>/`.

## Что где менять
- `commands.js` — данные бота (ник, сервер, описание, ссылка на GitHub) и список команд.
- `avatar.png` — положи свою аватарку с таким именем (пока показывается `avatar.svg`).
- `style.css` — цвета и темы (три кружка справа сверху переключают тему).
